# 🧠 Debabrata's — Portfolio

A modern, dark-themed personal portfolio website built to showcase my work at the intersection of **Data Analysis** and **Generative AI**.

> *Data Analyst by day. AI tinkerer by night. Physics graduate who never stopped asking "why?"*

---

## ✨ What's Inside

- **Single-page home** — About, Skills, Featured Project, Other Projects, Experience, and Contact all in one smooth scroll
- **LocalMind showcase** — A dedicated section for my privacy-first local LLM chat project (actively being refined)
- **Articles page** — Separate page for long-form writing on AI, science, and tech
- **Dark theme** — Inspired by the LocalMind UI aesthetic, blending deep navy with purple and cyan accents
- **Fully responsive** — Works on desktop, tablet, and mobile
- **Zero dependencies** — No frameworks, no build tools, no npm. Pure HTML, CSS, and vanilla JavaScript

## 🚀 Getting Started

No build step. No install. Just open it.

```bash
# Clone the repo
git clone https://github.com/Debo0013/Portfolio_v2.git

# Open in browser
open index.html
# or just double-click index.html
```

To host on **GitHub Pages**: go to repo Settings → Pages → set source to your branch root → done.
